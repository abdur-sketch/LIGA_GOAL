# Organizer Pilot Checklist — Phase 21

Checklist ini harus ditandatangani manusia sebelum keputusan produksi.

## Persiapan

- [ ] Organizer, reviewer, approver, verifikator, dan juri memakai akun sintetis/khusus pilot.
- [ ] Scope organisasi dan permission setiap aktor diverifikasi.
- [ ] Periode, kuota, persyaratan, privacy notice, dan kontak bantuan disetujui.
- [ ] Backup/restore staging dan prosedur insiden berhasil direhearsal.

## Alur pilot

- [ ] Organizer membuat kompetisi dan cabang tanpa mengubah modul sepak bola.
- [ ] Pendaftaran publik dibuka pada periode terbatas.
- [ ] Peserta individual/tim/instansi mendaftar dan menerima nomor/token.
- [ ] Verifikator memeriksa, meminta revisi, menolak, dan menyetujui sampel.
- [ ] Organizer menugaskan juri per sesi/babak dan mencatat konflik.
- [ ] Juri hanya melihat serta menilai sesi assignment-nya.
- [ ] Organizer mencabut satu assignment dan akses berhenti seketika.
- [ ] Juri submit hasil; reviewer berbeda melakukan review.
- [ ] Approver berbeda menyetujui; hasil terkunci.
- [ ] Publisher mempublikasikan; peserta melihat hasil publik yang benar.
- [ ] Reopen dengan alasan diuji dan seluruh history tetap tersedia.
